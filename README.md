# Flappy Bird Clone

A beginner-friendly Flappy Bird clone created with Python and Pygame.

## Features
- Smooth flying mechanics with gravity
- Animated bird with flapping wings
- Moving pipes and scrolling background
- Score counter and Game Over screen

## How to Play
1. Make sure you have Python installed.
2. Install Pygame by running `pip install pygame` (or `python -m pip install pygame-ce`).
3. Run the game using:
   ```bash
   python main.py
   ```
4. Press the **SPACEBAR** to jump.

Enjoy!
